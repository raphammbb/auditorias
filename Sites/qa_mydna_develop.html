01 — Visão Geral

Resumo Executivo

O site NÃO está pronto para produção no estado atual.

Existem pelo menos 4 bugs críticos que precisam ser resolvidos obrigatoriamente antes do deploy:

  1. Todos os formulários principais estão quebrados — A variável de ambiente NEXT_PUBLIC_API_URL não está configurada, tornando impossível capturar qualquer lead via formulário de contato ou agendamento de demo. Como todo o funil de conversão do site depende desses formulários, este é o bug de maior impacto de negócio.
  2. Página /ebooks/ com conteúdo duplicado — Todos os ebooks aparecem duas vezes na listagem (bug de fetch/renderização de dados), o que prejudica a credibilidade e usabilidade da página.
  3. Links quebrados no footer e menu — Dois links levam a páginas 404: "Sobre Nosotros" (/sobre-nosotros/ → deveria ser /about/) e "Outplacement" (/outplacement/ → não existe, o correto seria /products/outplacement/). A página de 404 também exibe texto em Português independente do idioma do contexto.
  4. Imagens placeholder em produção — As fotos dos testimonials são imagens de picsum.photos (banco de imagens aleatório), que não podem ser usadas em produção por questões de direitos de imagem e credibilidade.
02 — Diagnóstico

Tabela de Achados

16 problemas identificados durante os testes funcionais, agrupados por severidade.

Crítico6 achados
#1Formulário de Contato (/contact/)
Crítico

ERRO CRÍTICO: Ao submeter o formulário com todos os campos preenchidos e checkbox aceito, exibe a mensagem: "El servicio de envío no está configurado. Configure NEXT_PUBLIC_API_URL." O formulário não envia os dados.

Recomendação: Configurar a variável de ambiente NEXT_PUBLIC_API_URL no servidor de desenvolvimento (e produção). Verificar se o backend/API de envio está ativo e acessível.
#2Formulário de Demo (/demo/)
Crítico

MESMO ERRO CRÍTICO: O formulário de agendamento de demo também falha com a mensagem "El servicio de envío no está configurado. Configure NEXT_PUBLIC_API_URL." Todos os CTAs principais do site (Agendar Demo, Solicitar Cotización) apontam para #demo — ou seja, nenhum lead pode ser capturado.

Recomendação: Mesma correção: configurar NEXT_PUBLIC_API_URL. Este é o CTA principal do site inteiro e está completamente quebrado.
#3Página /outplacement/ — 404
Crítico

404 — Página não encontrada. A página de Outplacement é listada no menu Produtos ("Outplacement — Transición de carrera asistida") e no footer, mas a URL /outplacement/ retorna erro 404. A página de produto /products/outplacement/ existe, mas não há redirecionamento.

Recomendação: Criar a página em /outplacement/ ou corrigir os links no footer/menu para /products/outplacement/.
#4Footer — Link "Sobre Nosotros" → 404
Crítico

O footer linka para /sobre-nosotros/ que retorna 404. A página real está em /about/.

Recomendação: Corrigir o href no footer de /sobre-nosotros/ para /about/, ou criar um redirect 301.
#5Página /ebooks/ — Cards duplicados (79 cards)
Crítico

TODOS os cards de ebooks aparecem DUPLICADOS. A listagem exibe 79 cards no total sendo que cada ebook aparece exatamente 2 vezes. Isso indica um bug de renderização/fetch de dados que duplica o array retornado pela API/CMS.

Recomendação: Investigar a fonte de dados (CMS/API) que alimenta a listagem. Provável bug de concatenação dupla do array no fetch ou renderização React com estado inconsistente.
#13Formulário Market Salary (/products/market-salary/)
Crítico

O formulário do Market Salary possui campo "Área" com dropdown — provavelmente também usa NEXT_PUBLIC_API_URL e estará quebrado com o mesmo erro dos bugs #1 e #2. Não confirmado visualmente pois é o mesmo padrão de implementação.

Recomendação: Verificar e corrigir junto com os outros formulários após configurar a variável de ambiente NEXT_PUBLIC_API_URL.
Médio4 achados
#6Página de Erro 404 — Idioma errado
Médio

A página de erro 404 exibe texto em Português ("Página não encontrada", "A página que você procura não existe ou foi movida") mesmo quando acessada por usuário em contexto Espanhol (/sobre-nosotros/, /outplacement/). O footer da 404 também é a versão PT reduzida.

Recomendação: Implementar lógica de idioma na página 404: detectar a rota (/pt/ → PT, demais → ES). Criar versões ES/EN da página de erro.
#7Home — Seção "Demo em Vídeo" invisível
Médio

A seção de vídeo (entre Testimonios e FAQ) renderiza como um bloco completamente branco/invisível durante o scroll. O conteúdo existe no DOM mas não é visível — aparenta ser um problema de camadas CSS (z-index), fundo escuro com texto escuro, ou dependência de um embed de vídeo que não carrega.

Recomendação: Inspecionar o CSS da seção. Verificar se havia um <iframe> do YouTube que foi removido deixando o espaço sem conteúdo visível.
#8Home — Fotos dos Testimoniantes são placeholders
Médio

As fotos dos 3 testimoniantes (María González, Carlos Pérez, Ana Silva) são imagens placeholder de picsum.photos (imagens aleatórias de banco público), não fotografias reais ou de banco licenciado.

Recomendação: Substituir as URLs picsum.photos/seed/maria-rh-chile/... por fotos reais dos clientes (com autorização) ou avatares/ícones genéricos neutros antes do deploy.
#11Formulário de Contato — Validação visual ausente
Médio

Ao clicar em "Enviar mensaje" com todos os campos vazios, o campo "Nombre completo" fica em foco mas não exibe mensagens de erro visuais nos campos obrigatórios — sem borda vermelha, sem texto de erro. O feedback visual de validação está ausente.

Recomendação: Adicionar estilo de erro nos campos required (border-red, mensagem "Este campo es obligatorio") para melhorar UX.
Baixo6 achados
#10Home — Seção "Testimonios" parece vazia
Baixo

A seção Testimonios tem fundo #F9F5FF (roxo muito claro, quase branco) que na captura de scroll aparece como uma página em branco. O conteúdo existe no DOM e é acessível, mas visualmente parece um bloco vazio em algumas configurações de renderização/captura.

Recomendação: Avaliar aumentar o contraste do fundo da seção (ex: #F3EEFF) para evitar que pareça um erro de carregamento.
#12Footer — Link "Guía Salarial LATAM 2025" genérico
Baixo

O link "Guía Salarial LATAM 2025" no footer aponta para /ebooks/ (a listagem geral), não para a guia específica. Pode ser intencional, mas reduz a conversão.

Recomendação: Se existir uma landing page específica para a Guía Salarial, corrigir o link. Se não, manter como está.
#14Dropdown "Productos" — Abre só via clique
Baixo

O dropdown abre apenas via clique (não via hover). Comportamento atípico em desktop e pode confundir usuários. Funcionou corretamente após o segundo clique.

Recomendação: Avaliar se hover é o comportamento desejado. Se sim, adicionar onMouseEnter/onMouseLeave. Se clique é intencional, manter.
#15SEO — Inconsistência entre <title> e H1
Baixo

O título da página home em ES é "Recluta, Desarrolla y retiene el talento | Employee Experience y Talent Acquisition" — o hero diz "Desarrolla y retiene el talento que ya tienes" (sem "Recluta"). Inconsistência entre <title> e o H1.

Recomendação: Alinhar o <title> com o H1 principal para consistência de SEO e mensagem.
#16Página /employee-experience/ — Hero sem imagem
Baixo

Na página /employee-experience/ o hero tem fundo escuro mas nenhuma imagem no lado direito — o espaço está vazio, diferente da home que tem foto da profissional. Pode ser intencional, mas parece incompleto.

Recomendação: Confirmar se a ausência de imagem é intencional no hero escuro. Se não, adicionar a imagem de produto correspondente.
#17Todas as páginas — Respostas 503 em prefetch (HEAD)
Baixo

Nos logs de rede, múltiplas requisições HEAD retornam 503 (/hr-maturity/, /ebooks/, /en/, /pt/, /demo/, todas as páginas de produto). Trata-se de prefetch do Next.js — as páginas carregam via GET sem problema, mas o servidor de dev não suporta o método HEAD adequadamente.

Recomendação: Verificar a configuração do servidor Next.js em develop para responder corretamente a requisições HEAD. Não bloqueia produção mas pode afetar métricas de monitoramento.
